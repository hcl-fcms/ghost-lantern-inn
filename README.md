# 幽燈客棧 · 七夜百鬼宴

靈感源自 PC《百鬼夜宴》的原創 HTML 客棧經營小遊戲。並非官方重製，沒有使用原作圖像、音樂、程式或劇本文字。

## 遊玩

直接開啟 index.html，或使用 GitHub Pages。毋須安裝、API Key 或後端。支援手機點按、音效開關及本機自動存檔。

點燈開門 → 點選鬼客 → 選正確菜式 → 自動上菜收款 → 升級灶火與幽燈。每夜 75 秒，共七夜；招待至少 35 位及口碑至少 70 即獲名店結局。店租每夜 15–33 冥錢，低資金於夜間結算後補助至 20。空白鍵暫停，離開分頁自動暫停。

## 檔案

- index.html：頁面與介面
- style.css：響應式設計、CSS 原創鬼客與客棧
- game.js：遊戲規則、計時、音效及 localStorage 存檔
